# collision-safety-elearning
SCORM-style collision repair safety eLearning prototype featuring scenario-based practice, interactive hotspots, knowledge checks, progress tracking, and WCAG-oriented accessibility features.

This instructional design portfolio project demonstrates how adult learning theory, scenario-based practice, and interactive eLearning can support safer collision repair decisions. Built with HTML, CSS, and JavaScript. Vehicle illustration generated with AI for an instructional design prototype; not an official Tesla asset or affiliated with Tesla.
